# Ecosistema 02: Tareas — Requerimientos funcionales

El ecosistema de Tareas será el módulo encargado de registrar, clasificar, organizar y dar seguimiento al trabajo pendiente, incluyendo subtareas, fechas límite y control del tiempo dedicado a cada actividad.

La idea está bien delimitada para una primera versión. No necesitas comenzar con calendarios complejos, dependencias entre tareas o automatizaciones avanzadas. Lo importante es que puedas registrar lo que tienes que hacer, conocer su estado y controlar el tiempo que le dedicas.

## 1. Checklist de requerimientos funcionales

### A. Registro y administración de tareas

✓ TAR-001. Permitir crear una tarea nueva.
✓ TAR-002. Solicitar el nombre de la tarea.
✓ TAR-003. Registrar automáticamente la fecha y hora de creación de la tarea.
✓ TAR-004. Permitir establecer una fecha máxima de entrega o vencimiento.
✓ TAR-005. Permitir agregar una descripción de la tarea.
✓ TAR-006. Permitir guardar la tarea con su información registrada.
✓ TAR-007. Permitir consultar una tarea existente.
✓ TAR-008. Permitir modificar la información de una tarea después de crearla.
✓ TAR-009. Permitir eliminar una tarea.
✓ TAR-010. Solicitar confirmación antes de eliminar una tarea, para evitar pérdidas accidentales.

### B. Estados y seguimiento

✓ TAR-011. Clasificar las tareas en tres estados iniciales: Pendiente, En progreso y Completada.
✓ TAR-012. Mostrar las tareas organizadas según su estado.
✓ TAR-013. Permitir cambiar manualmente el estado de una tarea.
✓ TAR-014. Permitir marcar una tarea como completada.
✓ TAR-015. Permitir reabrir una tarea completada si es necesario.
✓ TAR-016. Mantener el registro de las tareas completadas para su consulta posterior.
✓ TAR-017. Mostrar de forma visible el estado actual de cada tarea.

### C. Subtareas

✓ TAR-018. Permitir agregar subtareas a una tarea principal.
✓ TAR-019. Permitir asignar un nombre a cada subtarea.
✓ TAR-020. Permitir agregar una descripción individual a cada subtarea, de forma opcional.
✓ TAR-021. Permitir marcar cada subtarea como completada o pendiente.
✓ TAR-022. Permitir editar las subtareas existentes.
✓ TAR-023. Permitir eliminar subtareas.
✓ TAR-024. Mostrar las subtareas asociadas a su tarea principal.
✓ TAR-025. Permitir crear tareas sin subtareas cuando la actividad no requiera desglosarse.

### D. Categorías y clasificación

✓ TAR-026. Permitir asignar una categoría a una tarea.
✓ TAR-027. Permitir crear categorías personalizadas, por ejemplo, materias, proyectos personales, trabajo o actividades administrativas.
✓ TAR-028. Permitir seleccionar una categoría existente al crear o editar una tarea.
✓ TAR-029. Permitir consultar las tareas agrupadas o filtradas por categoría.
✓ TAR-030. Permitir modificar la categoría asignada a una tarea.
✓ TAR-031. Permitir que una tarea no tenga categoría cuando su clasificación no sea necesaria.

### E. Cronómetro y estimación del tiempo

Este apartado tendrá dos formas de establecer el tiempo disponible: al crear la tarea o al comenzar a trabajar en ella.

✓ TAR-032. Permitir definir una duración estimada durante la creación de una tarea.
✓ TAR-033. Permitir registrar la duración estimada en horas y minutos.
✓ TAR-034. Permitir guardar una tarea sin establecer una duración estimada.
✓ TAR-035. Permitir iniciar un cronómetro desde la vista de detalles de la tarea.
✓ TAR-036. Si la tarea no tiene una duración estimada, solicitar cuánto tiempo se dispone para realizarla al iniciar el cronómetro.
✓ TAR-037. Permitir confirmar o modificar el tiempo disponible antes de iniciar el cronómetro.
✓ TAR-038. Mostrar el tiempo restante mientras el cronómetro esté activo.
✓ TAR-039. Permitir pausar y reanudar el cronómetro.
✓ TAR-040. Permitir detener el cronómetro.
✓ TAR-041. Notificar al usuario cuando se agote el tiempo establecido.
✓ TAR-042. Permitir consultar el tiempo registrado para una tarea.
✓ TAR-043. Mantener la relación entre el registro de tiempo y la tarea correspondiente.
✓ TAR-044. Evitar que se inicien varios cronómetros simultáneos para una misma tarea.

### F. Vista general y consulta de tareas

- TAR-045. Proporcionar una vista general de las tareas registradas.
- TAR-046. Permitir visualizar las tareas pendientes, en progreso y completadas.
- TAR-047. Mostrar el nombre, la categoría, el estado y la fecha límite de cada tarea cuando estén disponibles.
- TAR-048. Permitir abrir una tarea para consultar su descripción, subtareas, fechas y datos de tiempo.
- TAR-049. Mostrar las tareas vencidas o cuya fecha límite esté próxima.
- TAR-050. Actualizar la vista cuando una tarea cambie de estado o se modifique su información.

### G. Persistencia e historial

- TAR-051. Guardar las tareas para que permanezcan disponibles después de cerrar la aplicación.
- TAR-052. Conservar las categorías y las subtareas asociadas a cada tarea.
- TAR-053. Conservar el estado de cada tarea entre sesiones.
- TAR-054. Conservar los registros de tiempo asociados a las tareas.
- TAR-055. Mantener accesibles las tareas completadas, sin eliminarlas automáticamente.

## 2. Requerimientos no funcionales

- RNF-TAR-001. Persistencia: las tareas y sus datos deben conservarse al cerrar y volver a abrir la aplicación.
- RNF-TAR-002. Precisión temporal: el cronómetro debe medir el tiempo de manera fiable, incluso si la interfaz se actualiza con retraso.
- RNF-TAR-003. Consistencia: los cambios en una tarea deben conservar correctamente su relación con las subtareas, categorías y registros de tiempo.
- RNF-TAR-004. Usabilidad: crear, consultar y actualizar tareas debe requerir una interacción sencilla.
- RNF-TAR-005. Integridad: las fechas y duraciones deben validarse para evitar valores inválidos.
- RNF-TAR-006. Recuperación: al volver a abrir la aplicación, el sistema debe poder recuperar el estado del cronómetro o determinar si el tiempo disponible ya se agotó.



## IDEAS ADICIONALES
- Indicador de vencimiento: Mostrar visualmente si una tarea está vencida, próxima a vencer o todavía tiene tiempo. Se calcularía a partir de la fecha límite, sin añadir un cuarto estado a la tarea.
- Resumen de productividad: Mostrar cuántas tareas están pendientes, en progreso y completadas, así como el tiempo dedicado a ellas. Sería una vista informativa, sin convertir el módulo en un sistema complejo de estadísticas.
- Historial de sesiones de trabajo: Registrar cada sesión de cronómetro con su hora de inicio, hora de finalización y duración. Así podrías consultar cuánto tiempo dedicaste a una tarea en varias sesiones.
